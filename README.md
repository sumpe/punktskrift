# Piotrek's Punktskrift Press

Type a sentence and press it into a page of braille: the cells are embossed one by one onto warm paper, with the print in small type underneath.

Uncontracted braille (one cell per letter) in Swedish, English, German, Polish and Portuguese, each with its own national cells for accented letters, capitals, numbers and punctuation.

A sibling of Piotrek's [Polynoun](https://github.com/sumpe/polynoun) and [Polyverb](https://github.com/sumpe/polyverb) Tinctures.
